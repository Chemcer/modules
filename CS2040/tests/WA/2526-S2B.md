## Q1

```
foo ( node , val , count ) {
    if node == NULL
        return count
    if node . value == val
        return foo ( node . next , val , count + 1)
    else
        return foo ( node . next , val count )
}
```

It is clearlya linear travesal to count number of smth. Hence $O(n)$ time complexity

## Q2

```
total = 0
for i = 1 , ... , 10 {
    for j = 1 , ... , n {
        t = 1
        while ( t <= i ) {
            total = total + 1
            t = t + 1
        }
    }
}
```

Notice that the innermost loop happens at most 10 time, outermost loop at most 10 time, middle one n time. So $O(n)$ time complexity
